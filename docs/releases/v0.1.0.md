The first release of ACMS mk3, a pixel art editor written in Rust.

![The editor with an animation open](https://raw.githubusercontent.com/OttoApocalypse69/ACMS-MK3/main/docs/screenshots/animation.png)

## What is in it

- **Drawing:** pencil, eraser, line, rectangle, ellipse, bucket fill, gradient, eyedropper, move; rectangle, lasso and magic-wand selections; pixel-perfect strokes, mirror and radial symmetry, dither and shade inks, custom brushes, wrap-around drawing.
- **Layers and palettes:** groups, opacity, blend modes, lock and alpha lock, reference pictures; palette import and export (`.gpl`, `.hex`, `.pal`), ramps, replace and reduce.
- **Animation:** frames, linked cels, tags, onion skin, timeline and preview; export as GIF, spritesheet with Aseprite-style JSON, or PNG sequence; a timelapse of the undo history.
- **Game art:** tilesets and tilemap layers (edit one tile, every copy changes), slices with 9-slice centres and pivots, export to Tiled (`.tmj`) and CSV.
- **Lua scripting:** scripts add commands, filters and tools, in a sandbox. Five examples come with it; see `scripts/API.md`.
- **Comfort:** command palette (`Ctrl+Shift+P`), a keyboard shortcut editor, preferences, layouts, recent files, drag and drop, autosave with crash recovery, Aseprite import, dark and light themes.
- **Speed:** built for 120 fps while drawing on a 512 × 512 sprite with 20 layers.

## Downloads

Each file is the whole program, with nothing to install.

- **Windows:** `acms-mk3-windows-x86_64.zip`, then run `acms-app.exe`.
- **Linux:** `acms-mk3-linux-x86_64.tar.gz`, then run `acms-app`. It needs a desktop with Wayland or X11. Built by CI but not yet tried on a real Linux machine; reports welcome.

## Known limits

The full list is in [PROGRESS.md](https://github.com/OttoApocalypse69/ACMS-MK3/blob/main/PROGRESS.md). The main ones:

- No application icon and no installer.
- PNG files cannot be opened as sprites yet (only as references or palettes).
- Aseprite import leaves out tilemap layers.
- Two windows of the app share one recovery folder.
