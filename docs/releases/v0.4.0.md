ACMS mk3 0.4.0 hides something.

## New

- **A secret.** There is a small game inside ACMS now. It is not in any menu. If you grew up with a certain controller, you may already know how to find it; if you have a small sprite open when you do, you may recognise who is flying.
- **Hidden commands.** A command can be kept out of the command palette and the keyboard shortcut editor, so that some things stay a surprise.

Everything from [0.3.0](https://github.com/OttoApocalypse69/ACMS-MK3/releases/tag/v0.3.0), including CMG and Netpbm images, is still here.

## Downloads

| | |
|---|---|
| Windows installer | `acms-mk3-setup-x86_64.exe` |
| Windows, no install | `acms-mk3-windows-x86_64.zip`, then run `acms-app.exe` |
| Debian, Ubuntu | `acms-mk3_0.4.0-1_amd64.deb`, then `sudo apt install ./acms-mk3_0.4.0-1_amd64.deb` |
| Other Linux | `acms-mk3-linux-x86_64.tar.gz`, then run `acms-app` |

The downloads are not signed, so Windows SmartScreen may warn the first time; choose "More info", then "Run anyway".

The full list of what is known not to work yet is in [PROGRESS.md](https://github.com/OttoApocalypse69/ACMS-MK3/blob/main/PROGRESS.md).
