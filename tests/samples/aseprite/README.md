# Aseprite sample files

These files were saved by Aseprite. They come from the test data of the
[`aseprite-loader`](https://github.com/bikeshedder/aseprite-loader) crate (version 0.4.2), which
is licensed MIT OR Apache-2.0, and are used here to test `acms-io`'s Aseprite import against
files a real Aseprite wrote.
