ACMS mk3 gets an icon and installers.

## New

- **An icon**, drawn as pixel art, for the window, the task bar, the program file and `.acms` files.
- **A Windows installer.** It installs for you alone without asking for administrator rights, or for everyone if you choose. It adds a Start menu entry, an optional desktop shortcut, makes `.acms` files open in ACMS (optional), and lists ACMS under "Open with" for Aseprite files. It can be uninstalled from the Windows settings like any program.
- **A Debian / Ubuntu package** (`.deb`) with a menu entry, the icon, and `.acms` files known to the desktop.
- **Files named on the command line are opened**, which is how a double click on a file and "Open with" reach the app.

## Downloads

| | |
|---|---|
| Windows installer | `acms-mk3-setup-x86_64.exe` |
| Windows, no install | `acms-mk3-windows-x86_64.zip`, then run `acms-app.exe` |
| Debian, Ubuntu | `acms-mk3_0.2.0-1_amd64.deb`, then `sudo apt install ./acms-mk3_0.2.0-1_amd64.deb` |
| Other Linux | `acms-mk3-linux-x86_64.tar.gz`, then run `acms-app` |

The installer and the program are not signed, so Windows SmartScreen may warn the first time; choose "More info", then "Run anyway".

Everything from [0.1.0](https://github.com/OttoApocalypse69/ACMS-MK3/releases/tag/v0.1.0) is still here. The known limits are listed in [PROGRESS.md](https://github.com/OttoApocalypse69/ACMS-MK3/blob/main/PROGRESS.md).
