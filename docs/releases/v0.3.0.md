ACMS mk3 opens and writes two more kinds of image file.

## New

- **CMG character images** (`.cmg`), the text format of [CMG_raylib](https://www.cem.pp.ua/Akumarin/CMG_raylib): each character is one pixel in one of 94 fixed colours, one line per row. File → Import CMG Image… and Export CMG Image…. A colour CMG does not have is written as the nearest one, and ACMS says how many pixels that changed. ACMS reads CMG_raylib's own sample exactly as CMG_raylib draws it, pixel for pixel.
- **Netpbm images**: PBM (black and white), PGM (grey), PPM (colour), in their text and binary forms and up to 16 bits a sample, and PAM, which keeps transparency. File → Import / Export PBM / PGM / PPM / PAM Image…; the kind written follows the file name. A file holding several pictures opens as frames.
- Both open with File → Open, by dropping them on the window, from the command line, and with "Open with" in Windows once ACMS is installed.

## Good to know

- CMG has no file extension of its own; ACMS uses `.cmg`, and its import dialog also offers `.txt` and all files.
- Where ACMS reads a CMG file differently from CMG_raylib, it is on purpose: a character without a colour is transparent rather than light grey, a last line without a newline still counts, Windows line endings are understood, and the whole file is read rather than its first 10 239 bytes.
- PBM, PGM and PPM have no transparency: on export the picture is put on white, and PGM and PBM lose colour. ACMS says what changed; PAM keeps everything.

The full list of what is known not to work yet is in [PROGRESS.md](https://github.com/OttoApocalypse69/ACMS-MK3/blob/main/PROGRESS.md).
